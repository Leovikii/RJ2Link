# v1.3.0 重构计划

状态：重构主体完成，进入回归与真实站点验证  
目标：核心解耦、Preact 迁移、South Plus RJ 元数据预取和工程质量基线。

## 1. 发布目标

v1.3.0 是架构版本，不只是 UI 框架替换。完成标准包括：

- 业务核心不依赖 Vue 或 Preact。
- GM 网络和存储通过可测试端口访问。
- 网络请求具备超时、取消、错误分类和去重。
- 缓存、force 和跨标签页限流语义得到修正。
- Vue UI 完整迁移到 Preact，发布物不包含 Vue runtime。
- South Plus 实现预算受控的 RJ 元数据预取。
- 建立类型检查、单元测试和 CI 门禁。

## 2. 范围外事项

- 不进行大规模视觉重设计。
- 不更换用户脚本管理器或发布平台。
- 不新增后端服务器。
- 不预取封面、音频、ASMR ONE 或 South Plus 搜索结果。
- 不引入 Redux、路由器或大型 UI 组件库。
- 不在该版本全面重写本地化文案。

## 3. 里程碑

当前进度：M0–M6 主体完成；M7 的自动门禁、体积检查、本地桌面/移动端页面验证、移动端拖拽回归和真实站点冒烟已完成，发布候选仍待完成。

### M0：基线与测试支架

交付：

- 增加 `typecheck`、`test`、`lint` 命令。
- 补充 Vue/Preact 迁移期所需类型声明。
- 建立 Vitest 和内存 GM 适配器。
- 为 RJ code、日期、DLsite 解析和 South Plus 解析建立 fixture 测试。
- CI 执行 typecheck、test、build。

退出条件：

- 新增核心测试稳定运行。
- 已知旧类型错误形成明确清单，不再由 Vite 构建掩盖。

### M1：领域模型与基础设施端口

交付：

- `RjCode` 统一解析和归一化。
- `AppError` 与 `QueryState`。
- `HttpClient`、`KeyValueStorage` 等端口。
- Tampermonkey 和测试内存适配器。
- 统一 logger。

退出条件：

- 新服务代码不直接引用 GM 网络或存储全局变量。
- 所有请求路径可由假客户端测试。

### M2：网络、缓存与协调重构

交付：

- 请求超时、取消和状态校验。
- in-flight Promise 去重和 generation 保护。
- 统一缓存键、schema、TTL 和 force 语义。
- 修复关联作品缓存键不一致和 `useCache` 无效。
- 重写 South Plus 跨标签页限流租约。
- 修正网络异常被当成作品存在的问题。

退出条件：

- 超时、错误、空结果、强制刷新和并发行为有自动测试。
- 不再存在无限网络等待和同查询重复请求。

### M3：服务与应用控制器

交付：

- Metadata/Resource Provider 协议与显式 Registry。
- DLsite、SouthPlus、ASMR ONE Provider 实现。
- 框架无关的 Work Query Service。
- Popup/Resource Controller 及订阅接口。
- 现有 Vue UI 临时通过适配器消费新控制器。

退出条件：

- Vue 组件不再直接调用 GM 网络和远端解析逻辑。
- 同一 RJ 的弹窗、预取和刷新共享统一查询语义。
- 新资源站可在不修改通用控制器组件结构的情况下注册接入。

### M4：South Plus RJ 元数据预取

交付：

- 候选选择器。
- 空闲调度器和网络准入判断。
- 每页最多两个、串行、无重试的预取控制器。
- 用户查询优先和 in-flight 复用。
- 预算、取消和退化测试。

实现必须遵循 [预取功能规格](../features/southplus-rj-prefetch.md)。

退出条件：

- 所有规格验收场景通过自动测试。
- 预取不会触发图片、ASMR ONE 或 South Plus 网络请求。

### M5：Preact 基础与共享组件

交付：

- Vite 切换到 Preact preset。
- Preact Root 和控制器订阅 Hook。
- CSS Modules 基础。
- 迁移 `ActionButton`、`Badge`、`Cover`、`TagList`、`Row`、`PopupPanel`、`FloatingButton`。
- 共享组件状态测试。

退出条件：

- 共享组件不依赖 Vue。
- 桌面、移动端和 reduced-motion 基本状态可验证。

### M6：站点 UI 迁移

交付顺序：

1. DLsite 悬浮入口。
2. DLsite 搜索结果弹窗。
3. South Plus 元数据弹窗。
4. 事件委托和固定数量 Preact Root。
5. 删除 Vue store、popup bridge、`.vue` 文件和 Vue 依赖。

退出条件：

- 生产构建不包含 Vue runtime。
- 页面不会重复挂载 Root 或重复发起首次查询。
- 原有链接的键盘、中键和复制链接语义得到保留。

### M7：性能与发布验证

交付：

- MutationObserver 批处理和快速筛选。
- 生产 debug 日志关闭。
- 构建体积对比。
- 支持域名的人工冒烟验证清单。
- 更新三个用户 README 的 v1.3.0 功能说明。
- 发布候选构建和回滚说明。

退出条件：

- typecheck、test、build 全部通过。
- 无 P1/P2 已知回归。
- 请求预算和页面挂载数量符合规格。

## 4. 推荐提交边界

为降低评审风险，提交按以下主题拆分：

1. 文档和测试基线。
2. GM 端口与错误模型。
3. 查询缓存和请求去重。
4. South Plus 限流。
5. 应用控制器。
6. RJ 元数据预取。
7. Preact 构建与共享组件。
8. DLsite UI 迁移。
9. South Plus UI 迁移。
10. Vue 移除、性能和发布文档。

禁止把整个重构压成一个不可分辨的提交。

## 5. 风险与控制

| 风险 | 控制措施 |
| --- | --- |
| 迁移时复制旧竞态 | 先完成 M1–M3，再迁 UI |
| 双框架导致产物膨胀 | 仅迁移分支允许，RC 前删除 Vue |
| CSS 回归 | CSS Modules、截图基线、分组件迁移 |
| GM API 行为差异 | 端口适配和 Tampermonkey 冒烟测试 |
| 预取增加不必要流量 | 每页两请求预算、串行、网络准入、无重试 |
| South Plus 限流冲突 | 预取不访问 South Plus；搜索使用租约锁 |
| 网站 HTML 变化 | fixture 测试与解析错误分类 |
| 旧响应覆盖新状态 | 查询 generation 和统一控制器 |

## 6. 发布门槛

必须满足：

- `npm run typecheck` 通过。
- `npm run test` 通过。
- `npm run build` 通过。
- CI 对 pull request 执行上述检查。
- 生产 userscript metadata 权限最小且与实际调用一致。
- userscript 主页、问题反馈地址与仓库元数据指向当前 GitHub 仓库。
- Vue 依赖和构建插件已移除。
- 预取预算自动测试通过。
- South Plus、Spring Plus、Level Plus、DLsite 和 DLsite 台湾站完成适用页面冒烟检查。
- 三语言 README 与实际用户功能一致。

## 7. 回滚策略

- Preact 迁移前保留最后一个稳定的 v1.2.x tag。
- 预取功能通过单一配置常量或 feature flag 可关闭，不改变正常查询路径。
- 发布后若发现站点压力或异常请求，可先禁用预取并发布补丁，不需要回滚整个 UI。
- 缓存 schema 升级必须容忍旧记录并能安全失效，不执行破坏性全量迁移。
