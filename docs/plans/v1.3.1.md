# v1.3.1 修复与发布记录

状态：已发布。设计、功能代码、自动门禁、真实 Chrome 桌面/移动布局验证与最终实机确认均已完成。

目标：修复 DLsite 搜索结果中的长标题横向溢出，确保弹窗宽度始终受视口约束；多条结果使用不占布局宽度、静止淡出的悬浮滚动条，并统一优化外链图标。

## 1. 问题确认

当前 DLsite 结果 DOM 路径为 `.rwg-popup → .rwg-resource-panel → section → .rwg-results → li → a → strong`。桌面弹窗通常为 360px 宽，移动端宽度由 visual viewport 决定。

现有样式存在以下风险组合：

- `.rwg-results` 使用 `overflow: auto`，会同时允许横向和纵向滚动。
- 结果列表、列表项、链接和标题没有形成完整的 `min-width: 0` / `max-width: 100%` 收缩链。
- 标题没有显式恢复 `white-space: normal`，也没有为连续英文、URL 或连续 RJ 编号提供断行兜底。
- 外层 `.rwg-popup` 同样使用 `overflow: auto`；一旦后代形成较大的 min-content 宽度，列表或整个弹窗都可能出现横向滚动。
- 现有 12 条结果组件测试只验证列表数量和 class，不执行真实布局，因此不能发现 `scrollWidth > clientWidth`。

缩小字号只能减少普通标题的换行次数，不能保证不可断行内容或宿主样式干扰下不溢出，因此不作为主要修复手段。

## 2. 修复决策

修复限定在脚本自己的 DLsite 弹窗和结果列表，不修改网络、Provider、缓存或宿主页面布局。

### 2.1 从根因约束宽度

- 为弹窗 body、资源面板、Provider section、结果列表、`li` 和结果链接补齐 `min-width: 0`、`max-width: 100%` 与必要的 `box-sizing: border-box`。
- 为标题和元信息显式设置正常换行；标题使用 `overflow-wrap: anywhere` 处理连续英文、URL/RJ 编号，保持 `word-break: normal`，避免无条件逐字符破坏可读性。
- 保留完整标题的多行显示；首轮不使用固定行数截断，也不默认降低字号。只有真实布局验证证明必要时，才增加小幅响应式字号调整。

### 2.2 明确滚动轴

- `.rwg-results` 改为 `overflow-y: auto`、`overflow-x: hidden`，继续使用 300px 高度上限和滚动链隔离。
- 为 DLsite 资源弹窗增加明确的 modifier class，仅在该弹窗边界禁止横向滚动并保留必要的纵向滚动，避免扩大通用 `.rwg-popup` 的影响面。
- 禁止对 DLsite 宿主页面的 `html`、`body` 或其他页面级容器设置 `overflow-x: hidden`；横向裁切不能替代后代宽度修复。

### 2.3 悬浮滚动条与外链图标

- 隐藏结果列表的原生滚动槽，不使用 `scrollbar-gutter` 预留宽度；自绘滑块绝对定位于列表右缘，不参与卡片宽度计算。
- 移动端资源弹窗自身需要纵向滚动时同样隐藏原生滚动槽，避免标题栏和关闭按钮被滚动槽向左挤压；外层仍保留触控滚动能力。
- 滑块在滚动、指针操作或键盘进入列表时淡入，静止 850ms 后淡出；支持拖动滑块和点击轨道，并在 `prefers-reduced-motion` 下取消过渡动画。
- 公共外链 SVG 使用完整的窗口框与东北方向箭头，只保留在 ASMR ONE 等独立跳转按钮中；结果卡整卡已经是链接，不重复显示图标或为图标预留横向空间。

### 2.4 标题层级与 Provider 区块

- 弹窗顶栏显示 24px 项目 Logo、`RJ Warp Gate` 品牌名、当前 RJ 编号和关闭操作；不再显示信息价值较低的通用 `Search Result` 文案，RJ 编号使用低对比圆角徽章。
- ASMR.one 与 South Plus 使用相同的 Provider section、标题栏高度、字号、内边距和分隔线；来源差异只通过品牌色圆点、数量徽章和独立操作按钮表达。
- South Plus 结果数量从标题文本中的括号拆为独立徽章；列表置于同一圆角 section 内，减少三个标题区域互不相关的割裂感。
- DLsite 移动端底部弹窗支持点击弹窗外收起；弹窗内部交互和桌面悬浮弹窗保持原行为。

## 3. 实现顺序

### M0：建立回归场景

- 扩展 DLsite 本地 harness，加入普通长标题、连续 CJK、连续英文、URL 式内容和连续 RJ 编号，并保持至少 12 条结果。
- 保留组件测试对独立结果列表结构和稳定 key 的检查；真实尺寸断言放在浏览器布局验证中，不依赖 happy-dom 的伪布局。

### M1：实施局部 CSS 修复

- 只修改 `rwg-` 命名空间下的弹窗与结果列表样式，并由 DLsite 应用向 `PopupPanel` 传入资源弹窗 modifier class。
- 先补齐收缩与断行链，再限制横向滚动轴；不改变组件数据流、搜索请求或交互入口。
- 检查桌面悬浮弹窗和移动底部弹窗共用规则后的表现，避免只修一个断点。

### M2：验证与发布准备

- 运行 `npm run typecheck`、`npm run lint`、`npm run test`、`npm run build` 和 `git diff --check`。
- 在本地 DLsite harness 验证桌面、390px 移动视口和 320px 极窄视口。
- 在可访问时使用 Chrome + Tampermonkey 对真实 DLsite 页面做冒烟检查，并将结果、视口和测量值记录到本计划。
- 实现完成后同步三个用户 README 的 v1.3.1 修复说明；规划阶段不把尚未上线的行为写成已发布。

## 4. 验收标准

- 对普通多行标题、连续 CJK、连续英文、URL 式内容和连续 RJ 编号，`.rwg-results.scrollWidth <= .rwg-results.clientWidth`。
- 弹窗自身 `scrollWidth <= clientWidth`，所有结果卡的左右边界均位于弹窗内容区内。
- 至少 12 条结果时 `scrollHeight > clientHeight`，鼠标滚轮、触控和键盘仍可进行纵向滚动，且 `scrollLeft` 保持为 0。
- 原生滚动条宽度为 0，悬浮滑块不改变列表 `clientWidth`；滚动时可见、静止后淡出，并可拖动。
- 打开弹窗前后，宿主页面 `documentElement.scrollWidth` 不增加。
- 桌面 360px 弹窗、390px 移动视口和 320px 极窄视口均满足上述条件。
- 标题、作者和日期保持可读，结果卡整卡可点击且具备悬停与键盘焦点反馈；独立外链按钮不发生图标裁切。
- 不新增网络请求、GM 权限、运行时依赖或 Root。

## 5. 风险与控制

| 风险 | 控制措施 |
| --- | --- |
| 只隐藏横向滚动条但内容仍被撑宽 | 同时修复每级 Grid/列表子项的收缩链，并测量后代边界 |
| `overflow-wrap: anywhere` 影响正常标题排版 | 保持 `word-break: normal`，仅在正常断行机会不足时启用兜底 |
| 宿主样式覆盖 `white-space` | 使用严格限定在 `.rwg-root .rwg-results` 下的显式规则，并在 harness 模拟干扰 |
| 结果卡提示不足 | 整卡保留手型光标、悬停边框/背景与键盘焦点环，不再依赖占宽的重复箭头 |
| 通用弹窗规则影响 South Plus 作品弹窗 | 优先限定 DLsite 资源面板；若调整通用 `.rwg-popup`，同时回归 `.rwg-popup--work` |

## 6. 范围外事项

- 不进行弹窗视觉重设计或全局字号调整。
- 不截断或改写 Provider 返回的标题内容。
- 不修改 South Plus 搜索协调、网络请求、缓存和诊断行为。
- 不通过页面级横向裁切修复 DLsite 或其他宿主站点。
